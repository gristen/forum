Схема БД — forum

построено по database/migrations
1:N — belongsTo / hasMany N:M — belongsToMany доп. ключ morph
Наведи на таблицу — подсветятся только её связи. Клик — закрепить, клик по фону или Esc — сбросить.
Схема собрана автоматически по файлам database/migrations/*. Служебные таблицы (sessions, password_reset_tokens, cache, jobs) не показаны.
⚠ В миграции create_conversation_user_table ключ объявлен как ->constrained('conversation'), но таблицы conversation нет — есть conversations. На чистой БД эта миграция упадёт.
